# Three-minute demo storyboard

## Show, don't tell
0:00–0:20 — Hook: group chats are noisy, deadlines and decisions disappear.
0:20–0:55 — Send messages between **two real browser sessions**; establish real-time functionality.
0:55–1:35 — Show the AI catch-up card: missed conversations summarised by topic and tasks.
1:35–2:05 — Search naturally: “When did we decide to meet?” Locate the correct original message.
2:05–2:35 — Show the AI detecting an event or unresolved choice; approve an ICS invite or poll.
2:35–3:00 — Architecture: separate chat and AI FastAPI services; chat keeps working if AI service fails. Close with impact.

## Seed realistic chats
Use 15–30 realistic team messages about event date, venue, food, budget, responsibilities and open choices. Rehearse exact queries before recording.

## QA before recording
- Two browsers actually exchange messages
- All key links/buttons function
- No model key appears on screen
- Keep a local recording file and verify playback
- Show the team, code, demo, and value in a 3-minute video
